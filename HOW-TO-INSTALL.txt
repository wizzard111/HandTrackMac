=====================================================================
  HANDTRACK ДЛЯ MAC — ПОШАГОВАЯ УСТАНОВКА
  (English version below)
=====================================================================

HandTrack распознаёт жесты рук, может скрыть ваше лицо, рисовать в воздухе
и показывает всё это в звонках (Zoom, Telegram, Discord, Google Meet).

Нужно: macOS 12 Monterey или новее (Apple M1/M2/M3/M4 или Intel),
веб-камера, интернет на время установки, ~1,5 ГБ свободного места.

Про камеру для звонков: Apple разрешает виртуальные камеры только
программам с платной подписью разработчика. Поэтому на Mac HandTrack
отправляет картинку в бесплатную «OBS Virtual Camera» — установщик
предложит поставить OBS. Сам OBS держать открытым не нужно.


---------------------------------------------------------------------
ШАГ 1. СКАЧАЙТЕ И РАСПАКУЙТЕ
---------------------------------------------------------------------

  1. Страница Releases -> handtrack-macos.zip
     (или зелёная кнопка «Code» -> «Download ZIP»).
  2. Дважды щёлкните по архиву — появится папка HandTrack. В ней:
       Install HandTrack.command     <- установщик
       Uninstall HandTrack.command   <- удаление
       HOW-TO-INSTALL.txt            <- эта инструкция
  Права на запуск у файлов уже есть.


---------------------------------------------------------------------
ШАГ 2. ЗАПУСТИТЕ УСТАНОВЩИК
---------------------------------------------------------------------

  1. Дважды щёлкните  Install HandTrack.command

  2. macOS скажет, что не может проверить файл. Это потому, что
     программа бесплатная и не подписана в Apple. Разрешите запуск:
       - macOS 15 Sequoia и новее: нажмите «Готово», откройте
         Системные настройки -> Конфиденциальность и безопасность,
         прокрутите вниз и нажмите «Всё равно открыть», затем снова
         «Открыть» и введите пароль Mac;
       - macOS 12-14: правой кнопкой по файлу -> «Открыть» -> «Открыть».
     Это нужно только один раз.

  3. Откроется Терминал с шагами. Установка собирает программу прямо
     на вашем Mac: первый раз 3-6 минут. Если спросит пароль Mac —
     введите (при вводе он не виден, это нормально).

  4. «Установить OBS сейчас?» — нажмите Enter (= да).

  5. HandTrack запустится и спросит доступ к камере — «Разрешить».
     Дальше открывайте HandTrack из «Программ» или Launchpad.


---------------------------------------------------------------------
ШАГ 3. ОДИН РАЗ ВКЛЮЧИТЕ КАМЕРУ OBS
---------------------------------------------------------------------

  1. Откройте OBS из «Программ», пропустите мастер настройки.
  2. Справа внизу нажмите «Запустить виртуальную камеру».
  3. macOS попросит разрешить системное расширение:
     Системные настройки -> Конфиденциальность и безопасность ->
     «Разрешить». Затем закройте OBS.


---------------------------------------------------------------------
ШАГ 4. ПОЛЬЗУЙТЕСЬ
---------------------------------------------------------------------

  1. В HandTrack нажмите «СТАРТ», включите «Транслировать в
     виртуальную камеру».
  2. В Zoom / Telegram / Discord выберите камеру «OBS Virtual Camera».

  * «Скрыть лицо» — чёрная маска на лице и значок COVERING.
  * Рисование: соедините большой и указательный пальцы и ведите рукой.
  * «Мои жесты» с клавишами: Системные настройки -> Конфиденциальность
    и безопасность -> Универсальный доступ -> включите HandTrack.


---------------------------------------------------------------------
УДАЛЕНИЕ
---------------------------------------------------------------------

  Дважды щёлкните  Uninstall HandTrack.command  (в этой папке).
  Он удалит программу и её разрешения и спросит про настройки.
  OBS удаляется отдельно: перетащите его из «Программ» в Корзину.


---------------------------------------------------------------------
ЕСЛИ ЧТО-ТО НЕ ТАК
---------------------------------------------------------------------

  * Чёрный экран в HandTrack: Системные настройки -> Конфиденциальность
    и безопасность -> Камера -> включите HandTrack, перезапустите его.
  * Нет «OBS Virtual Camera» в звонке: выполните шаг 3 и перезапустите
    приложение для звонков.
  * Что-то сломалось или пропало — просто запустите установку ещё раз:
    она проверит, чего не хватает, и поставит только это, ничего
    не перекачивая и не перезаписывая.
  * Журнал установки: install.log в этой папке.
    Журнал программы: ~/Library/Application Support/HandTrack/logs


=====================================================================
  HANDTRACK FOR MAC — STEP BY STEP
=====================================================================

You need macOS 12+ (Apple silicon or Intel), a webcam, internet during setup.
Apple only allows virtual cameras from apps with a paid developer signature,
so on a Mac HandTrack feeds the free "OBS Virtual Camera".

1. Releases -> handtrack-macos.zip (or "Code" -> "Download ZIP"); double-click it.
2. Double-click "Install HandTrack.command". macOS says it cannot verify it:
   macOS 15+: System Settings -> Privacy & Security -> "Open Anyway";
   macOS 12-14: right-click the file -> Open -> Open. Only once.
3. Terminal shows each step; the app is built on your Mac (3-6 min the first time).
   Answer Enter to install OBS. Allow camera access when HandTrack asks.
4. Once: open OBS -> "Start Virtual Camera" -> allow the system extension in
   System Settings -> Privacy & Security; then quit OBS.
5. In HandTrack press START and enable "Stream to virtual camera";
   in your call app pick "OBS Virtual Camera".
UNINSTALL: double-click "Uninstall HandTrack.command".
